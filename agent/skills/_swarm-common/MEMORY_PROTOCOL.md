# Skill Memory Protocol — swarm-\* 共通（正典）

`~/.claude/skill-memory/<skill>/MEMORY.md` は**その skill 自体の運用知見**（判定基準が実態と乖離した傾向、
閾値の妥当値、誤検知の傾向など）を蓄積する場所。プロジェクト単位の軌跡ログ / `@fix_plan.md` とは別軸。

- 開始時: ファイルが存在すれば読み、判断材料にする。無ければ気にせず進める（空ファイルを作らない）。
- 完了時: 今回のミッション固有の詳細ではなく、**今後の起動全般に通用する知見**が得られた場合のみ、簡潔に追記する。
  既存内容と重複するものは追記しない。一般化できる学びが無ければ何も書かない。
- プロジェクト固有の学びは軌跡ログ（`agents-log-lib.sh` が返すパス）へ。
